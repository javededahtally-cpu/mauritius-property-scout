Property Scout: set it up on your PC and iPhone

About 30 minutes, once. Afterwards the scan runs every hour on GitHub’s free servers, even when your PC is off. Nothing uses Claude or costs anything.

PC = do this on your Windows laptop   iPhone = do this on your iPhone

Set up GitHub

  1. PCUnzip the packageFind mauritius-property-scout.zip in Downloads, right-click it → Extract All → Extract. You get a folder mauritius-property-scout containing .github, docs, scout.py and a few other files.
  2. PCCreate a free GitHub accountGo to github.com/signup and follow the steps (email, password, username). Your username becomes part of your app’s address.
  3. PCCreate the repositoryClick + (top right) → New repository. Name: mauritius-property-scout. Choose Public. Click Create repository.

    Public is what makes the hourly runs and the app hosting free. Your matches will be viewable by anyone who finds the address; your passwords stay hidden (step 7).

  4. PCUpload the filesOn the new repository page, click the link uploading an existing file. Open the unzipped mauritius-property-scout folder in File Explorer, press Ctrl+A to select everything inside it, and drag it all onto the browser page. When the upload finishes, click Commit changes.

    Check that .github appears in the file list afterwards. If it doesn’t: Add file → Create new file, type the name .github/workflows/scout.yml, paste in the contents of the separate scout.yml file, and commit.

  5. PCLet the scanner save its resultsIn the repository: Settings → Actions → General. Scroll to Workflow permissions, choose Read and write permissions, click Save.

Phone alerts

  1. iPhoneInstall ntfy and pick a topicInstall ntfy from the App Store (free). Open it, tap +, type a topic name only you would guess, for example mps-jay-7k3q9, tap Subscribe, and allow notifications. Write the topic name down exactly.
  2. PCGive GitHub your alert detailsIn the repository: Settings → Secrets and variables → Actions → New repository secret. Add:
    NameValue
    NTFY_TOPICyour ntfy topic name from step 6
    EMAIL_TOoptional: where emails go (e.g. your Hotmail address)
    SMTP_USERoptional: a Gmail address to send from
    SMTP_PASSWORDoptional: that Gmail account’s 16-letter app password

    Email is optional; the iPhone push is enough. Sending needs a Gmail account (Hotmail can receive but not send for this). To get a Gmail app password: Google Account → Security → turn on 2-Step Verification → search “App passwords” → create one.

Turn it on

  1. PCSwitch on the app’s web addressSettings → Pages. Source: Deploy from a branch. Branch: main, folder /docs → Save. After 1–2 minutes the page shows your address: https://YOUR-USERNAME.github.io/mauritius-property-scout/
  2. PCRun the first scanOpen the Actions tab (click the green button to enable workflows if asked) → Property Scout scan → Run workflow → Run workflow. It takes 5–15 minutes; a green tick means it worked. Your iPhone gets up to 10 alerts for the best new finds.
  3. PCInstall the app on your laptopOpen your app address in Edge → ⋯ menu → Apps → Install this site as an app. (Chrome: ⋮ → Cast, save and share → Install page as app.) It appears in the Start menu; right-click it there to pin it to the taskbar.
  4. iPhonePut the app on your home screenOpen your app address in Safari (easiest: email or text it to yourself from the PC). Tap Share → Add to Home Screen → Add.
  5. PCCheck which sites the scanner can readIn the app: Activity → Which websites the scanner can read. “Refused” means a site turns automated visitors away. Some (L’Express Property especially) may do so.

Stop the Claude version

  1. PCDelete the Claude scheduled taskOnce matches appear in the new app, open Claude, find the scheduled task Mauritius Property Scout sweep, and pause or delete it. That task is what used credits; the new app never touches Claude.

Day to day

  • New matches appear on both devices automatically every hour.
  • Your own changes (shortlist, rejects, photos you add) stay on the device where you made them.
  • To change what the scanner looks for: edit in My searches or Settings, then tap Download for the scanner PC, and in GitHub use Add file → Upload files to upload scanner-settings.json → Commit changes.
  • If GitHub ever emails that the scheduled workflow was disabled, open the Actions tab and click Enable workflow.

Optional alternative: run_windows.bat runs one scan on your PC and opens the app at http://localhost:8765; schedule_windows.bat makes the PC scan every hour while it’s on (needs Python from python.org). This version isn’t visible on the iPhone.
