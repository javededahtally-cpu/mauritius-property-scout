Alerts

The scanner runs every hour. Alerts arrive as a push in the ntfy app on your iPhone and, if you set it up, as an email. Where they go is set in your GitHub repository (Settings → Secrets), not here.

Sources

Exchange rate

The scanner refreshes the pound-to-rupee rate (mid-market) on every scan. To use your bank's rate instead, enter it here; leave it blank to use the market rate.

Photos in the app

Photos load straight from each advert's website. A few sites don't allow that; for those, open the advert, or add your own photos from any match (Photos → Add photos). Photos you add are kept in this browser, on this device.

Save to your phone

New matches arrive from the hourly scan on every device. Your own changes (shortlist, rejects, searches, settings, added photos) are kept in this browser on this device. To keep a copy or move them to another device, save a backup file and restore it there. On iPhone, choose Save to Files and pick OneDrive. On Android, choose the OneDrive folder or Downloads.

Add it to your home screen

This opens the scout like an app, with its own icon. No sign-in is needed.

iPhone (Safari)
  1. Open this page in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Name it "Property Scout" and tap Add.
Android (Chrome)
  1. Open this page in Chrome.
  2. Tap the ⋮ menu, then Add to Home screen.
  3. Name it "Property Scout" and tap Add.
Windows PC (Edge or Chrome)
  1. Open this page in Edge or Chrome.
  2. Edge: ⋯ menu → Apps → Install this site as an app. Chrome: ⋮ menu → Cast, save and share → Install page as app.
  3. It then appears in the Start menu and can be pinned to the taskbar.
